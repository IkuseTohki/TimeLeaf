# ローカルアプリケーション設定 (Local App Settings)

アプリケーションの起動やOSとの連携に必要な、クライアントPC固有の設定情報を定義する。
これらの設定ファイルは、プロジェクト間で共有されるデータではなく、OSのユーザープロファイル配下の隠しディレクトリに保存・管理される（MUST）。

## 1. 保存先ディレクトリ

すべてのローカル設定ファイルは、以下のパスに配置する（MUST）。

- **パス:** `{UserHome}\.timeleaf\`
  - (例: Windows環境における `C:\Users\{UserName}\.timeleaf\`)

## 2. ユーザー識別ファイル (`seed.json`)

ユーザーのアイデンティティの根幹となるGUIDを永続化するファイル。
（※参照: ADR-0004 ユーザー管理とプロフィール同期方針）

- **Id (`Id`):** Guid (アプリケーション初回起動時に生成される一意の識別子。以降、変更してはならない / MUST)

## 3. アプリケーション設定ファイル (`settings.json`)

UIの振る舞いや、アプリケーション全体の環境設定を保持するファイル。以下のプロパティを含む（MUST）。

- **データ保存先パス (`StoragePath`):** string
  - アプリケーションが作成する全プロジェクトデータ（`TimeLeaf_Data_Root`）を保存・参照するベースフォルダの絶対パス。
- **テーマ設定 (`Theme`):** string
  - 適用するUIテーマ。`Light`, `Dark`, `Forest` のいずれか。
- **OS通知の有効化 (`EnableOsNotification`):** bool
  - バックグラウンド更新検知時等に、OS標準のトースト通知を利用するかどうか。
- **アプリ内通知の有効化 (`EnableAppNotification`):** bool
  - 操作時の即時フィードバックとして、アプリ内のスナックバーを利用するかどうか。
- **閉じるボタンで最小化 (`MinimizeOnClose`):** bool
  - メインウィンドウの「閉じる(X)」ボタンを押下した際、プロセスを完全終了する（`false`）か、タスクトレイに常駐して最小化する（`true`）かの制御フラグ。
