# テーマ・パレット：フォレスト (Forest)

本ドキュメントでは、TimeLeaf 独自の「フォレスト」テーマにおける色彩設計、および共通仕様に対する形状のオーバーライドを定義する。

---

## 1. デザイン意図：深い森の安らぎと集中

フォレストテーマは、ユーザーが深い森の中にいるような「静謐さ」を感じることを目的としている。

---

## 2. カラーコード定義 (HEX)

共通のデザイン・トークンに対し、以下の具体的な値を割り当てる。

| トークン名              | HEX 値    | 役割・イメージ                         |
| :---------------------- | :-------- | :------------------------------------- |
| **SurfaceBaseBrush**    | `#F9F7F2` | 非常に薄いベージュ。紙や土の下地。     |
| **SurfaceLayer1Brush**  | `#2D5A27` | 深い森の緑。サイドバー、ヘッダー背景。 |
| **BrandPrimaryBrush**   | `#4A7C44` | 中間の緑。主要なアクション（決定等）。 |
| **OnBrandPrimaryBrush** | `#FFFFFF` | ブランド色の上での文字・アイコン。     |
| **TextPrimaryBrush**    | `#2D5A27` | 深緑のテキスト。黒よりも柔らかい。     |
| **TextSecondaryBrush**  | `#706E6B` | 落ち着いたグレー。補足情報。           |
| **OutlineBaseBrush**    | `#E0DDD5` | 土色の境界線。背景と調和。             |

---

## 3. 形状のオーバーライド (Shape Overrides)

TimeLeaf の「オーガニック」なコンセプトを実現するため、共通仕様の `CornerRadius` を以下の通り上書きする。

- **ControlCornerRadius**: **20px** (共通の 4px から変更)
- **ContainerCornerRadius**: **24px〜32px** (共通の 8px から変更)

これにより、既存のボタン分類や振る舞いを維持しつつ、TimeLeaf 独自の柔らかな外観を実現する。
