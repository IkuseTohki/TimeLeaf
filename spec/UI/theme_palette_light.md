# テーマ・パレット：ライト (Light)

本ドキュメントでは、アプリケーションの標準となる「ライトテーマ」における具体的な色彩設計を定義する。

---

## 1. デザイン意図：清潔感と信頼性

ライトテーマは、白を基調とした広々とした空間（ネガティブスペース）を活かし、情報の整理整頓と読みやすさを最優先する。

- **明瞭なコントラスト**: 背景と文字のコントラストを高く保ち、あらゆる環境下での視認性を確保する。
- **標準的な操作感**: ユーザーが慣れ親しんだデスクトップアプリのトーンを踏襲し、迷いのない操作を支援する。

---

## 2. カラーコード定義 (HEX)

共通のデザイン・トークンに対し、`LeafKit.UI` の標準値をベースとした具体的な値を割り当てる。

| トークン名              | HEX 値    | 役割・イメージ                             |
| :---------------------- | :-------- | :----------------------------------------- |
| **SurfaceBaseBrush**    | `#FFFFFF` | 純白。ウィンドウ全体の背景。               |
| **SurfaceLayer1Brush**  | `#F7F9FA` | ごく薄いグレー。サイドパネル、リスト背景。 |
| **BrandPrimaryBrush**   | `#0078D4` | 標準的な青。主要なアクション。             |
| **OnBrandPrimaryBrush** | `#FFFFFF` | ブランド色の上での文字・アイコン。         |
| **TextPrimaryBrush**    | `#333333` | 濃いグレー（黒に近い）。本文、見出し。     |
| **TextSecondaryBrush**  | `#666666` | 中間のグレー。補足情報、ヒント。           |
| **OutlineBaseBrush**    | `#E1E1E1` | 薄いグレーの境界線。要素の区切り。         |

---

## 3. 形状の仕様

ライトテーマでは、共通仕様である **4px（ControlCornerRadius）** および **8px（ContainerCornerRadius）** をそのまま適用し、シャープでモダンな印象を維持する。
