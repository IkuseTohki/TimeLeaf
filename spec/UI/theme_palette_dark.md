# テーマ・パレット：ダーク (Dark)

本ドキュメントでは、長時間の使用における疲労軽減と集中力の維持を目的とした「ダークテーマ」における具体的な色彩設計を定義する。

---

## 1. デザイン意図：没入感と眼精疲労の軽減

ダークテーマは、発光を抑えた暗色の背景を使用し、コンテンツを浮かび上がらせることで、ユーザーの集中力を高める。

- **低彩度の背景**: 純粋な黒（#000000）を避け、わずかに彩度を落とした深いグレーを使用することで、文字のハレーションを抑制する。
- **階層の表現**: 色の明度差（Luminance）を利用して、面（Surface）の重なりを直感的に表現する。

---

## 2. カラーコード定義 (HEX)

共通のデザイン・トークンに対し、ダークモードに最適化した具体的な値を割り当てる。

| トークン名              | HEX 値    | 役割・イメージ                             |
| :---------------------- | :-------- | :----------------------------------------- |
| **SurfaceBaseBrush**    | `#1E1E1E` | 深いグレー。ウィンドウ全体の背景。         |
| **SurfaceLayer1Brush**  | `#2D2D2D` | 一段階明るいグレー。サイドパネル、カード。 |
| **BrandPrimaryBrush**   | `#0078D4` | 青（彩度を維持）。主要なアクション。       |
| **OnBrandPrimaryBrush** | `#FFFFFF` | ブランド色の上での文字・アイコン。         |
| **TextPrimaryBrush**    | `#E1E1E1` | 薄いグレー（白に近い）。本文、見出し。     |
| **TextSecondaryBrush**  | `#969696` | 中間のグレー。補足情報。                   |
| **OutlineBaseBrush**    | `#3E3E42` | 暗いグレーの境界線。背景と馴染ませる。     |

---

## 3. 形状の仕様

ダークテーマでは、共通仕様である **4px（ControlCornerRadius）** および **8px（ContainerCornerRadius）** をそのまま適用する。暗色の背景においては、角の形状よりも「明度による輪郭」が形状認識の主体となる。
