# TimeLeaf 仕様書 (Documentation)

ネットワークが制限された環境下でも効率的にプロジェクト管理を行うための、デスクトップアプリケーション `TimeLeaf` の仕様書群である。
本ドキュメントは人間とAIが共に理解・実装しやすい形式（AI-Native）で記述されている。

## ディレクトリ構成

- **1_Requirements/**: 要件定義（目的、スコープ、ユースケース）
- **2_Architecture/**: アーキテクチャ設計（技術スタック、状態管理）
- **3_Schema/**: データ設計（データモデル、ファイルストレージ・同期方式）
- **4_UI/**: UI/UX設計（デザインシステム、画面構成）
- **5_Testing/**: テスト方針
- **adr/**: アーキテクチャ決定記録 (Architecture Decision Records)
