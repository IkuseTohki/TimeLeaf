# 全タスク管理仕様書 (ALL TASKS)

## 1. 概要

「ALL TASKS」画面は、アプリケーションに登録されているすべてのプロジェクトのタスクを一元的に表示・管理するための画面である。
ユーザーはプロジェクトの枠を超えて、自分に関連する作業や、差し迫った期限のタスクを俯瞰することができる。

## 2. 表示項目

一覧表示される各タスクには、以下の情報が含まれる。

- **プロジェクト名**: そのタスクが属するプロジェクトの名称。
- **タスク名**: 作業内容。
- **担当者**: アサインされているメンバー。
- **状態 (Status)**: 未着手、進行中、完了等の進捗状況。
- **優先度 (Priority)**: 緊急度・重要度。
- **期限 (Deadline)**: 完了予定日。

## 3. 機能要件

### 3.1. 集約ロジック

- メモリ上にロードされているすべてのプロジェクトからタスクを抽出する。
- プロジェクトリストが変更（追加・削除）された場合、一覧を自動的に更新する。
- 個別のプロジェクト内でタスクが追加・削除・変更された場合、一覧に即座に反映する。

### 3.2. フィルタリング

以下の条件でタスクを絞り込めること。

- **ステータス**: すべて / 未完了のみ / 完了済み。
- **キーワード**: プロジェクト名またはタスク名による部分一致検索。

### 3.3. ソート

デフォルトでは以下の順序で表示する。

1. 期限（昇順、未設定は後方）
2. 優先度（降順）
3. プロジェクト名（昇順）

### 3.4. 操作

- タスクをクリックすることで、該当するプロジェクトのワークスペースへ遷移し、そのタスクの詳細を表示（またはサイドパネルを開く）する。

## 4. UI/UX デザイン

- 表形式（DataGrid または ListView）による一覧表示を基本とする。
- プロジェクトごとに背景色やラベルを変えることで、所属プロジェクトを視覚的に区別しやすくする。
- 期限が切れているタスクや、今日が期限のタスクは強調表示（赤字など）を行う。
