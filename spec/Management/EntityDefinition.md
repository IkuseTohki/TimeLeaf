# エンティティ定義仕様書

## 1. 概要

TimeLeafにおけるプロジェクトおよびタスクのデータ構造を定義する。
本仕様書では、オフライン環境下での「変更の蓄積」と「不変性（Immutability）」を前提とした、各エンティティのプロパティ詳細を記述する。

データモデルは、コンフリクトを最小化するために「関心事」に基づいたプロパティ・グループに分割して管理される。
すべての日時プロパティはJST（日本標準時）として保持・管理される。

## 2. プロジェクト（Project）

プロジェクトはシステムにおける最上位の管理単位であり、共通の設定とマイルストーンを保持する。

### 2.1. プロジェクト基本情報

プロジェクトの識別と分類を行うための不変、あるいは低頻度で更新される属性。

- **プロジェクトID**: システム内で一意の識別子（GUID）。
- **プロジェクト名**: チームで識別するための名称。
- **概要**: プロジェクトの目的や背景の詳細説明。
- **分類**: 開発、機能追加、改善、不具合対応などの種別。
- **優先度**: プロジェクト全体の重要度（高、中、低）。
- **状態**: 準備中、進行中、完了、一時停止などのライフサイクル状態。
- **ヘルスステータス**: 順調、注意、遅延などの主観的な健全性指標。

### 2.2. 期間・工数設定

計画の基準となるスケジュールと、進捗計算のアルゴリズムを定義する。

- **開始予定日 / 終了予定日**: プロジェクト全体の計画期間。
- **稼働日設定**: 土日祝日の扱いやチーム固有の休日設定。
- **進捗定義**: タスク数ベース、または工数ベースのいずれで進捗率を算出するか。

### 2.3. 分類・整理

- **マイルストーン**: 重要な節目となる日付とラベルのリスト。
- **タグ**: 横断的な検索や分類のためのラベル。

## 3. タスク（Task）

タスクは具体的な作業単位であり、複数のプロパティ・グループに分割して変更を管理する。

### 3.1. タスク基本属性（TaskBasic）

作業の内容と分類を定義する。

- **タスクID**: システム内で一意の識別子（GUID）。
- **プロジェクトID**: 所属するプロジェクトの参照。
- **タスク名**: 作業内容の要約。
- **詳細説明**: 手順や要件を記述するMarkdown形式のテキスト。
- **優先度**: 作業の緊急度・重要度。
- **親タスクID**: 階層構造（サブタスク）を実現するための参照。
- **削除フラグ**: 論理削除状態を示す真偽値。

### 3.2. アサイン情報（TaskAssignment）

責任と関心の所在を定義する。

- **作業担当者**: 実作業を行うメンバーの識別子。
- **レビュアー**: 成果物の確認を行う責任者。
- **ウォッチャー**: 通知を受け取る関心担当者のリスト。

### 3.3. スケジュールと見積（TaskSchedule）

「計画の精度」を測定するための時間的指標。

- **開始予定日 / 終了予定日**: 計画上の作業期間。
- **期限 (Deadline)**: 移動不可能な最終納期。
- **見積工数（初回）**: 作業着手前に合意した期待工数。
- **見積工数（修正後）**: 状況変化に応じて再見積した最新の期待工数。
- **必要日数**: 工数とは別に、カレンダー上で占有する日数。

### 3.4. 進捗と実績（TaskProgress）

現在の動的な状態と、実際に費やされたコスト。

- **状態**: 未着手、着手中、レビュー待ち、完了などの進捗段階。
- **完了理由**: 対応済み、対応不要、重複などの終了背景。
- **開始日 / 終了日**: 実際に作業を開始・完了した日付。
- **実績工数（累積）**: そのタスクに投下された合計時間。
- **進捗率**: 0〜100%の数値による詳細進捗。

### 3.5. 関連性（TaskRelation）

- **依存タスク**: 着手・完了の前提条件となる他タスクのIDリスト。
- **関連タスク**: 参照や影響範囲として紐づく他タスクのIDリスト。

## 4. 蓄積型データ

変更履歴として積み上げられ、過去の内容が上書きされないデータ。

### 4.1. コメント（Comment）

- **コメントID**: 発言の一意な識別子（GUID）。
- **タスクID**: 紐づくタスクの参照。
- **投稿者**: 発言したユーザー。
- **内容**: 発言本文（Markdown対応）。
- **添付ファイルリンク**: 関連資料へのポインタリスト。
