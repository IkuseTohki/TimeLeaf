# メイン画面レイアウト (Main Window Layout)

## 1. オーガニック・サイドバー (Organic Sidebar)

画面左側に、アプリケーション全体のナビゲーションとプロジェクトの「幹」となるサイドバーを配置する。  
ユーザーの作業領域を最大化するため、以下の2つの状態をシームレスに切り替え可能とする（MUST）。

- **展開状態 (Expanded):** アイコン ＋ テキストラベルを表示する。
- **折りたたみ状態 (Collapsed):** アイコンのみを表示し、解像度（専有面積）を下げてメイン作業領域を広げる。

### サイドバーの構成要素

サイドバーには上から順に以下の要素を配置する（MUST）。

1. Home
2. All Tasks
3. Notifications
4. プロジェクト新規作成アイコン (`+`)
5. Projects (進行中プロジェクトの一覧リスト)
