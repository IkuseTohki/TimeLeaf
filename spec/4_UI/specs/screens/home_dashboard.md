# Home画面仕様 (Home Screen)

アプリケーション起動時に表示される、ユーザー自身の作業コンテキストを集約したダッシュボード画面。以下の要素を配置する（MUST）。

- **未着手のタスク:** ユーザーにアサインされた着手待ちタスク。
- **進行中:** 現在作業中のタスク。
- **今週の完了:** 直近で達成した成果の可視化。
- **健全性 (Health):** ワークロード等のステータスインジケーター。
- **期限が近いタスク:** 全プロジェクトを対象としたリスト表示（上限5件）。
- **マイルストーン:** 全プロジェクトを対象とした直近の節目リスト（上限5件）。
- **進行中プロジェクト:** アクティブなプロジェクトへのクイックアクセス。
- **アクティビティ:** ユーザーの操作全般を紹介・追跡するタイムライン。
