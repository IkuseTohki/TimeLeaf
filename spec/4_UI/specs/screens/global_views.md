# 横断ビューと通知画面 (Global Views & Notifications)

## 1. All Tasks 画面

全プロジェクトのタスクを横断的に操作・俯瞰するビュー。ユーザーが「今、何に着手すべきか」を瞬時に判断できる設計とする。

### 1.1 デフォルトのソート規則 (Default Sorting Rule)

ユーザーが意図的にソート順を変更しない限り、すべてのタスクは常に以下の優先順位にしたがって並べ替えられなければならない（MUST）。

1. **期限 (`Deadline`):** 昇順（期日が近いものから表示）
2. **優先度 (`Priority`):** 降順（高優先度のものから表示）
3. **プロジェクト名 (`Project.Name`):** 昇順（辞書順）

### 1.2 視覚的フィードバック (Visual Feedback)

- **期限の切迫:** 「今日が期限（Today）」または「期限切れ（Overdue）」となっているタスクは、リストやボード上で該当のテキスト（または行自体）を `Theme.Colors.Error` （デザイントークンのエラーステータス色）で強調表示し、ユーザーの注意を喚起する（MUST）。
- **サブビュー切替:** ユーザーの目的に応じて `List`, `Timeline`, `Grid` の表示形式を切り替え可能とする（MUST）。
- **フィルター:** 状態、期限、プロジェクト等による絞り込み機能を提供する（MUST）。

## 2. Notifications (通知センター)

見逃してはならない重要なイベントを集約する画面。以下を対象としてリストアップする（MUST）。

- 期限切れ（Overdue）のタスク
- 本日到達したマイルストーン
