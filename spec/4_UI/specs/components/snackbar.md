# スナックバー仕様 (Snackbar)

## 1. 概要 (Overview)

アプリ操作中の即時フィードバック（保存完了、エラー等）を非破壊的に伝えるため、画面下部に一時的に表示される通知コンポーネント。

## 2. アニメーション仕様 (Animation Specs)

ユーザーの視線を穏やかに誘導するため、以下の厳密なアニメーション数値を適用する（MUST）。

- **出現時の動き (Entrance):** 下方向へ `20px` オフセットした位置から、元の位置へスライドアップしつつフェードイン（不透明度 0% -> 100%）する。
- **所要時間 (Duration):** `200ms`
- **イージング曲線 (Easing):** `QuarticEaseOut` （初速が速く、滑らかに減速する）

## 3. 表示の持続時間 (Duration Time)

重要度に応じて、スナックバーが自動的に消えるまでの時間を制御する（MUST）。

- **通常通知 (Info / Success):** `5秒` (5000ms)
- **重要通知 (Warning / Error):** `10秒` (10000ms)
