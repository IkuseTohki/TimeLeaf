# モーダル / ダイアログ仕様 (Modal & Dialog)

## 1. オーバーレイ層 (Overlay / Backdrop)

モーダル表示時、背面のコンテンツ（メイン画面）の操作がブロックされていることを視覚的に伝えるため、背景にオーバーレイ・シャドウを適用する。

- **背景シャドウ色:** `Black` (黒)
- **不透明度 (Opacity):** `40%`

## 2. アニメーション仕様 (Animation Specs)

ダイアログが画面の手前に浮き上がってくるような立体感と自然さを演出するため、以下のトランジションを適用する（MUST）。

- **出現時の動き (Entrance):** ダイアログ自身のスケール（Scale）を `95%` から `100%` へ拡大させながら、同時にフェードイン（不透明度 0% -> 100%）させる。
- **所要時間 / イージング:** （※注: スナックバー等との一貫性を保つため、デフォルトとして `200ms`, `QuarticEaseOut` の適用を推奨する / SHOULD）
