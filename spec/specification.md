# TimeLeaf アプリケーション仕様書

## 1. プロジェクト概要 (Overview)

セキュリティ要件などによりネットワークが制限された環境下において、チーム横断での効率的なプロジェクト管理を実現するデスクトップアプリケーションである。RDBMSを使用せず、JSONファイルを介したフォルダベースのデータ同期アプローチを採用することで、オフライン環境下での自律的なチームコラボレーションを可能とする。

データの永続化と同期をファイルシステムに依存させることで、外部インフラを必要とせず、USBメモリや既存のファイル共有サーバーを介したデータの持ち運び・共有を実現する。

## 2. アーキテクチャおよびシステム要件 (Architecture & System Requirements)

多様な実行環境（とくにレガシーシステムが残るオフライン環境）に対応するため、以下の技術スタックおよびアーキテクチャ制約をMUST（必須）とする。

- **GUIフレームワーク:** WPF (Windows Presentation Foundation)
- **アーキテクチャパターン:** クリーンアーキテクチャ、MVVM、リアクティブプログラミング
- **マルチターゲット設計:**
  - メイン環境: `.NET 10` (最新言語機能とパフォーマンス最適化)
  - 互換環境: `.NET Core 3.1` (レガシー環境への対応保証)
- **データフォーマット:** JSON (人間が可読であり、ベンダーロックインを回避するため)
- **非同期I/Oの徹底:** ファイルI/Oを伴うRepositoryおよびUseCaseのメソッドは、UIスレッドのブロックを回避するため常に `Task` または `IAsyncEnumerable` を返すこと。
- **ポータビリティ:** インストール不要（または最小構成）で動作し、データディレクトリを含めてポータブルに持ち運び可能であること。
- **常駐機能:** ウィンドウを閉じてもシステムトレイに常駐し、バックグラウンドで他メンバーのファイル更新を検知・通知する。

## 3. 用語集およびデータモデル (Glossary & Data Model)

システム内で取り扱う主要なエンティティおよびプロパティを定義する。JSONシリアライズ時のプロパティ名として英名を適用する。

### 3.1 プロジェクト (Project)

プロジェクト全体を管理するエンティティ。

- **Id (`ProjectId`):** GUID。システム内で一意の識別子。必須。
- **名前 (`Name`):** 文字列。チームで識別するための名称。必須。
- **概要 (`Description`):** 文字列。目的や背景の詳細説明。任意。
- **分類 (`Category`):** 文字列。開発、機能追加、改善、不具合対応などの種別。デフォルト: `未分類`。
- **状態 (`Status`):** 文字列。ライフサイクル状態。`準備中(Preparing)`, `進行中(InProgress)`, `完了(Completed)`, `一時停止(Paused)` のいずれか。デフォルト: `準備中`。
- **マイルストーン (`Milestones`):** リスト。重要な節目となる日付とラベルのコレクション。
- **タグ (`Tags`):** 文字列リスト。横断検索用のラベル。
- **開始予定日 (`PlannedStartDate`):** 日付。プロジェクト全体の計画開始日。任意。
- **終了予定日 (`PlannedEndDate`):** 日付。プロジェクト全体の計画終了日。任意。
- **進捗定義 (`ProgressCalculationMethod`):** 文字列。進捗率の算出基準。`TaskCount` (タスク数ベース) または `Workload` (工数ベース) のいずれか。デフォルト: `TaskCount`。

### 3.2 タスク (Task)

具体的な作業単位を管理するエンティティ。

- **Id (`TaskId`):** GUID。一意の識別子。必須。
- **プロジェクトId (`ProjectId`):** GUID。所属プロジェクトの参照。必須。
- **名前 (`Name`):** 文字列。作業内容の要約。必須。
- **詳細説明 (`Description`):** 文字列。Markdown形式の手順や要件。
- **優先度 (`Priority`):** 整数または列挙型。緊急度・重要度。デフォルト: `中(Medium)`。
- **親タスクId (`ParentTaskId`):** GUID。サブタスクの場合のみ値を保持する。任意。
- **論理削除 (`IsDeleted`):** 真偽値。削除状態を示す。デフォルト: `false`。
- **作業担当者 (`Assignee`):** GUID。実作業を行うメンバーの識別子。必須。
- **レビュアー (`Reviewer`):** 文字列。成果物の確認を行う責任者。
- **ウォッチャー (`Watchers`):** 文字列リスト。通知を受け取る関心担当者。
- **開始予定日 (`PlannedStartDate`) / 終了予定日 (`PlannedEndDate`):** 日付。計画上の作業期間。
- **期限 (`Deadline`):** 日付。移動不可能な最終納期。
- **初回見積工数 (`InitialEstimatedHours`):** 数値。作業着手前に合意した期待工数。
- **修正後見積工数 (`RevisedEstimatedHours`):** 数値。状況変化に応じて再見積した最新の期待工数。
- **必要日数 (`RequiredDays`):** 数値。工数とは別に、カレンダー上で占有する日数。
- **状態 (`Status`):** 文字列。`未着手(Todo)`, `着手中(InProgress)`, `レビュー待ち(InReview)`, `完了(Done)` など。デフォルト: `未着手`。
- **完了理由 (`CompletionReason`):** 文字列。`対応済み`, `対応不要`, `重複` など。状態が完了の場合のみ設定。
- **開始日 (`ActualStartDate`) / 終了日 (`ActualEndDate`):** 日付。実際に作業を開始・完了した日。
- **実績工数 (`ActualHours`):** 数値。投下された合計時間。デフォルト: `0`。
- **進捗率 (`ProgressPercentage`):** 整数。0〜100の数値。デフォルト: `0`。
- **依存タスク (`DependencyTaskIds`):** GUIDリスト。着手・完了の前提となる他タスク。
- **関連タスク (`RelatedTaskIds`):** GUIDリスト。参照・影響範囲として紐づく他タスク。

### 3.3 コメント (Comment)

タスクに紐づくインライン・ディスカッションを管理するエンティティ。

- **Id (`CommentId`):** GUID。一意の識別子。必須。
- **タスクId (`TaskId`):** GUID。紐づくタスクの参照。必須。
- **投稿者 (`Author`):** 文字列。発言したユーザー。必須。
- **内容 (`Content`):** 文字列。発言本文（Markdown対応）。必須。
- **添付ファイル (`Attachments`):** 文字列リスト。関連資料へのファイルパスまたはリンク。

## 4. 機能要件 (Functional Requirements)

### 4.1 横断タスクビュー (ALL TASKS)

全プロジェクトを横断してタスクを管理する機能。

- **MUST:** ユーザーはプロジェクトの枠を超えて、すべてのタスクを単一のリストまたはボードで表示できる。
- **MUST:** 状態、担当者、タグ、期限による複数条件のフィルタリングを提供する。

### 4.2 通知システム (Alerts & Notifications)

ファイル同期による他者の更新や期限を通知する多層的なフィードバック機能。

- **MUST:** スナックバー (Snackbar) を用いて、アプリ操作中の保存成功やエラーなどの即時フィードバックを非破壊的に表示する。
- **MUST:** 通知センター (Notification Center) を実装し、未確認の更新や期限切れタスクの履歴を管理する。サイドバーのバッジで未読件数を表示する。
- **MUST:** OS標準通知 (Windows Toast Notification) を連携させ、アプリが背面に隠れている、またはシステムトレイに常駐している状態でも通知を受け取れるようにする。

#### 通知発生の振る舞い定義 (BDD)

- **Given:** TimeLeafがシステムトレイに常駐している
- **When:** バックグラウンド処理がデータフォルダ内の `task_xxx.json` の外部更新（他メンバーによる変更）を検知する
- **Then:** Windows Toast 通知で「タスク '[タスク名]' が [更新者] によって更新されました」と表示する
- **And:** アプリ内の通知センターの未読バッジカウントを+1する
