# アプリケーションホスト・動作仕様 (Application Host)

## 1. ライフサイクルと起動 (Application Lifecycle)

- アプリケーション起動時、最初に DI コンテナの構築とサービス群の初期化を行う（MUST）。
- 初期化完了後、指定された全体データルート配下のプロジェクト情報および `users/` プロフィールの初期ロード（Replay処理）をバックグラウンドで実行し、完了後にメインUIを描画する（SHOULD）。

## 2. 常駐動作 (System Tray Residency)

ネットワーク切断環境下における継続的なデータ監視を維持するため、アプリケーションは常駐型として振る舞う。

- ユーザーがメインウィンドウの「閉じる（X）」ボタンを押下した際、アプリケーションのプロセスを終了させず、ウィンドウを非表示にしてシステムトレイ（タスクバー）へ最小化する（MUST）。
- システムトレイのアイコンから、メインウィンドウの再表示、およびアプリケーションの完全終了（プロセス終了）を行うコンテキストメニューを提供する（MUST）。

## 3. OS連携と通知 (OS Notifications)

バックグラウンド動作中（メインウィンドウ非表示時）の更新を取りこぼさないよう、OSのネイティブ通知を利用する。

- Infrastructure層の監視コンポーネントが、外部メンバーによる新規タスク作成やコメント追加等の重要な変更を検知した場合、OS標準の Windows Toast Notification を発行する（MUST）。
- トースト通知には、操作を行った `UserId`（プロフィールから解決した `DisplayName`）と、対象エンティティの概要を含める（SHOULD）。
